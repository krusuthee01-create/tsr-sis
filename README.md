# TSR-SIS ระบบสารสนเทศนักเรียน โรงเรียนอนุบาลเทพสุนทรินทร์

ระบบสารสนเทศนักเรียนชั้น อ.1–ป.6 (18 ห้อง นักเรียนประมาณ 500 คน ครูและบุคลากร 35 คน)
ใช้ได้บนมือถือ iPad และคอมพิวเตอร์ ติดตั้งเป็นแอปบนหน้าจอโฮมได้ (PWA) และเช็กชื่อได้แม้ไม่มีสัญญาณ

- ติดตั้งระบบ: [docs/SETUP.md](docs/SETUP.md)
- คู่มือผู้ใช้: อยู่ในระบบ (เมนู "คู่มือการใช้งาน" และปุ่ม ? ทุกหน้า) เนื้อหาอยู่ที่ `src/lib/help.ts`

## เฟส 1 (เวอร์ชันนี้)

| โมดูล | ทำได้ |
|---|---|
| ทะเบียนนักเรียน | นำเข้าจาก DMC (แสดงตัวอย่างก่อนยืนยัน นำเข้าซ้ำได้), ค้นหา, ประวัติรายคน, เปลี่ยนสถานะพร้อมเหตุผล, ย้ายห้อง, เรียงเลขที่, เลื่อนชั้นสิ้นปี |
| เช็กชื่อ | เข้าแถว (5 สถานะ), ดื่มนม, แปรงฟัน (ตัดคนขาด/ลาออกอัตโนมัติ), เช็กชื่อประจำวิชา ป.1–6 (ดึงคนขาด/ลาจากตอนเช้า), ใช้งานออฟไลน์ |
| งานครูที่ปรึกษา | หน้าแรกแสดงงานวันนี้ของห้อง, นักเรียนขาดเรียนติดกัน, ข้อมูลเพิ่มเติมที่ DMC ไม่มี |
| ทะเบียนครู | ข้อมูลครู, อนุมัติบัญชี, บทบาท, บัญชี Google หรือชื่อผู้ใช้/รหัสผ่าน, วิชาที่สอน, ครูที่ปรึกษา/ครูพี่เลี้ยง |
| รายงานและระบบ | สรุปการมาเรียนรายเดือน (Excel / ปพ.5 / พิมพ์ PDF), ภาพรวมรายวัน, การใช้งานระบบ, ประวัติการแก้ไข, ตั้งค่า (ปฏิทิน วันหยุด คาบ รายวิชา) |

เฟส 2: ภาวะโภชนาการ, เยี่ยมบ้าน, คัดกรอง, SDQ/EQ, ส่งเสริมพัฒนา
เฟส 3: นำเข้าผลการเรียนจากโปรแกรม ปพ.5, สถิติเกรด/คุณลักษณะ, ตาราง SAR

## หลักการออกแบบ

- **ไม่กรอกซ้ำ**: ข้อมูลประจำตัวนักเรียนมาจาก DMC เท่านั้น, ดื่มนม/แปรงฟัน/เช็กชื่อรายวิชาดึงคนที่ไม่มาจากการเช็กชื่อเข้าแถว, รายวิชานำเข้าจากไฟล์ ปพ.5, ส่งออกเวลาเรียนเป็นรูปแบบชีต ปพ.5
- **เร็ว**: เว็บและฐานข้อมูลอยู่สิงคโปร์, บันทึกลงเครื่องก่อนแล้วส่งเบื้องหลัง (กดบันทึกแล้วขึ้นสำเร็จทันที), บันทึกทั้งห้องในคำสั่งเดียว
- **ปลอดภัย (PDPA)**: สิทธิ์บังคับที่ฐานข้อมูล (Row Level Security) ครูประจำวิชาและครูพี่เลี้ยงไม่เห็นข้อมูลผู้ปกครอง/ที่อยู่, ทุกการแก้ไขบันทึกในประวัติ

## โครงสร้าง

```
supabase/migrations/   โครงสร้างฐานข้อมูล สิทธิ์ และฟังก์ชัน (รันตามลำดับ)
src/app/               หน้าจอ (Next.js App Router)
src/lib/               ตรรกะหลัก: dmc.ts (อ่านไฟล์ DMC), pp5.ts, thai-date.ts, offline-queue.ts, help.ts
tests/                 ทดสอบ: lib.test.ts (ฟังก์ชัน), sql/ (สิทธิ์และ RPC), e2e/ (ใช้งานจริงผ่านเบราว์เซอร์)
scripts/local-stack/   Supabase จำลองในเครื่องสำหรับพัฒนา (ไม่ต้องใช้ Docker)
```

## พัฒนาในเครื่อง

```bash
npm install
npm test                 # ทดสอบฟังก์ชัน
npm run test:sql         # ทดสอบฐานข้อมูล (ต้องมี PostgreSQL ที่ localhost)
scripts/local-stack/start.sh > .env.local.tmp   # เปิด Supabase จำลอง (PostgreSQL ที่ 127.0.0.1:54329)
tail -3 .env.local.tmp > .env.local && npm run build && npm start
python3 tests/e2e/make-fake-dmc.py /tmp/tsr-fake-dmc.xlsx
npm run test:e2e         # ต้องติดตั้ง playwright
```

> ห้ามนำไฟล์ข้อมูลจริงของนักเรียน (.xlsx / .xlsb) เข้า git — `.gitignore` กันไว้แล้ว ใช้ไฟล์ปลอมจาก `make-fake-dmc.py` สำหรับทดสอบ
